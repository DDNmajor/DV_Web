Đăng replay

Không cần biết file nằm ở đâu — chọn thư mục replay của game, web sẽ tự tìm và hiện danh sách trận để bạn tick chọn. File chưa được gửi đi cho tới khi bạn bấm Đăng.

Bạn có thể chọn và xem trước replay ngay, nhưng cần đăng nhập hoặc tạo tài khoản để đăng lên web.

Cách 1 · Chọn thư mục replay của bạn

  1. Bấm Copy đường dẫn:
  2. Bấm nút Chọn thư mục replay bên dưới. Trong hộp thoại hiện ra, bấm vào thanh địa chỉ ở trên cùng, dán (Ctrl + V) rồi nhấn Enter.
  3. Bấm Select Folder (Chọn thư mục). Nếu trình duyệt hỏi có cho xem file không, chọn Xem file / View files.

Không chọn được? .

Cách 2 · Mở sẵn thư mục

Đã cài Ayame Installer? Bấm nút dưới, thư mục replay sẽ tự mở — kéo file từ đó thả vào ô bên dưới.
