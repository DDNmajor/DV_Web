Cài replay vào game bằng 1 nút bấm

Trình duyệt không được phép tự ghi file vào thư mục của game. Ayame Installer là một script nhỏ cho Windows giúp việc đó: cài một lần, sau đó mỗi lần bấm Cài vào game trên web, replay sẽ tự vào mục Archive của Idol Showdown.

⬇ Tải Ayame Installer (.zip) Windows 10/11 · khoảng 10 KB · không cần quyền Administrator

Cài đặt (1 phút)

  1. Mở file AyameInstaller.zip vừa tải, bấm Extract all (Giải nén tất cả) → Extract.
  2. Trong thư mục vừa giải nén, bấm đúp setup.cmd.
    Nếu Windows hiện "Windows protected your PC", bấm More info → Run anyway. Đây là cảnh báo chung cho mọi file tải từ Internet chưa được ký số.
  3. Thấy thông báo "Đã cài xong Ayame Installer!" là xong. Có thể xoá thư mục vừa giải nén.

Sử dụng

  1. Mở một replay trên web, bấm 🎮 Cài vào game.
  2. Trình duyệt hỏi "Mở Windows PowerShell?" → chọn Mở. Có thể tick Luôn cho phép để lần sau khỏi hỏi.
  3. Vài giây sau hiện thông báo "Đã cài replay vào game". Mở Idol Showdown → Archive để xem.

Lưu ý phiên bản: game chỉ mở được replay ghi ở đúng phiên bản game bạn đang chơi. Replay của bản cũ hơn sẽ hiện là "corrupted" trong Archive. Mỗi replay trên web đều ghi rõ phiên bản.

Trình cài làm gì trên máy bạn?

  • Chép script ayame-handler.ps1 và config.json (địa chỉ web này) vào %LOCALAPPDATA%\AyameInstaller.
  • Đăng ký đường link ayame:// cho tài khoản Windows của bạn (HKEY_CURRENT_USER\Software\Classes\ayame).
  • Tạo lối tắt "Idol Showdown - Replay Archive" trong Start Menu để mở nhanh thư mục replay.

Khi bạn bấm Cài vào game, script chỉ tải file từ địa chỉ ghi trong config.json, kiểm tra đúng là file replay và khớp mã SHA-256 của server, rồi ghi vào thư mục Archive. Nó không ghi đè file có sẵn và không làm gì khác. Toàn bộ mã nguồn nằm trong file ayame-handler.ps1 — mở bằng Notepad để xem.

Gỡ cài đặt

Bấm Windows + R, dán %LOCALAPPDATA%\AyameInstaller\uninstall.cmd rồi Enter. Replay đã cài vẫn còn nguyên trong game.
